X-PrintfScope软件为串口示波器软件，通过C语言Printf函数即可实现波形显示，使用简单方便。
波形显示部分采用了Iocomp控件，支持拖动、缩放、保存等功能。
当前为测试版本，欢迎使用！

使用前请先安装Iocomp控件。

安装方法：
* 安装前请先断开网络。
* 双击 Iocomp ActiveX 402SP1 文件夹下setup.exe 开始安装。
* 根据提示填写，并选择下一步，直至出现New KeyCode，输入8B54FDFE1F，单击Add，下一步。
* 选择合适路径，下一步
* 选择ActiveX（默认已选），下一步
* 二进制位置，建议选择默认路径，下一步
* 选择“Do Not Install Support for OPC Features”，下一步
* 输入注册信息，内容可以随便输入英文字母，注意以下几点，否则NEXT不可用
  1、Telephone 输入需要超过8个字符
  2、Email Address 输入完整Email格式，例如hhhh@daa.com
  3、Where was product purchased？ 选择Iocomp Software
* OS 选择 2008，Development 选择 VS2008。选择Send按钮，重试两次，第三次点击确定。
* 下一步，完成安装。
