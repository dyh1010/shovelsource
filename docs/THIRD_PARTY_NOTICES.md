# 第三方来源与许可

本库整理用户提供的厂家资料，保留原始文件名、原厂说明与版权文本。它不将第三方资料重新授权，也不以整个仓库的一份 MIT / Apache 许可证覆盖厂家文件。

| 来源 | 内容 | 许可处理 |
| --- | --- | --- |
| 逐飞科技 RT1064_Library-master | RT1064 库、示例、硬件与工具资料 | 原始根目录 LICENSE 为 GPL-3.0 文本；各组件还包含独立许可，使用具体文件时同时核对文件头与组件许可 |
| NXP / ARM / FatFs 等上游组件 | RT1064 SDK、CMSIS、文件系统等 | 保留组件 LICENSE 与版权声明 |
| 塔克创新 | MC520、TB6612 资料、教程与例程 | 归档时未发现覆盖全部资料的统一许可；不推定允许公开再分发 |
| OLED / OpenART mini 提供方 | 屏幕、视觉资料与工具 | 以各原始文件的声明为准；不推定整包采用开源许可 |

默认使用私有仓库。若后续公开，应先逐项确认厂家文档、视频、安装包及压缩例程的再分发许可。

RT1064 原始 .gitmodules 引用了逐飞助手的 Gitee 仓库。本次是本地资料快照，不拉取外部子模块，也不把嵌套 .gitmodules 当作已初始化子模块；原文件完整保存在 Release 中。
