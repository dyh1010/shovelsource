# 维护约定

## 分支职责

- main：总导航、来源说明、校验清单。
- codex/mc520、codex/tb6612、codex/rt1064-coreboard、codex/rt1064-motherboard、codex/oled-096-7pin、codex/openart-vision：各硬件资料快照与模块说明。
- 实际开发从对应资料分支创建功能分支；不要将六个资料分支整包合并以免重复引入厂家工程。

## 提交资料更新

记录厂家、产品型号、硬件版本、发布日期与获取来源。保留原许可证；不要覆盖原厂资料后继续沿用旧的校验值。更新资料后重新生成 manifest、归档校验值及新版本 Release。

RT1064 两个分支中的共用库在首次归档时来自同一份源目录。更新共用库时同步两分支，并核对一致性；不宣称它们会自动同步。

## 记录验证

每次实测至少记录硬件版本、接线、电源、IDE / 编译器版本、固件版本、关键参数、操作步骤与结果。将“资料中描述”“成功编译”“烧录成功”“硬件实测通过”分开记录。

不要提交凭据、IDE 私有设置、临时输出或未说明来源的大型二进制。大型原始资料通过新 Release 分包保存，并提供 SHA-256 校验值。
